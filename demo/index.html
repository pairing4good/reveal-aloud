13. A long note

Split into short utterances, because Chrome silently truncates long ones. Advance early and it stops mid-sentence — try it.

This note is deliberately long. Chrome cuts off any single utterance after about fifteen seconds, which would leave a note like this one stopping halfway through with no error and no explanation.

So the note is broken into sentences before it ever reaches the browser. Each sentence is spoken on its own, which also gives the narrator somewhere natural to breathe, and gives you a clean place to interrupt.

Try pressing the right arrow key right now, in the middle of this sentence. The narrator stops immediately and starts reading the next slide instead. Try going backwards too — it works exactly the same way.

14. Tidying up after a bracket

Removing a stage direction can strand a comma or leave a double space. Those are cleaned up so the voice does not stumble.
